# 监管 vs 扩张（Regulate vs Expand）

一个单文件网页卡牌策略游戏。架空背景：恒盛集团在「扩张」与「监管」两条明暗中博弈。

- 零依赖、纯前端：双击 `index.html` 即可在浏览器中游玩，无需服务器；也可直接通过 GitHub Pages 静态网址访问。
- 双角色对抗：你扮演**扩张方**或**监管方**，与 AI 对弈，后者在两种身份下都会按难度强化。
- 明暗双线：明面资产 / 负债与隐性埋雷并存，终局或第三回合有概率暴露隐性债务。
- 难度梯度：新手 / 普通 / 困难三档，困难模式证据线高、AI 出牌更猛。

## 玩法要点

- 扩张方靠投资翻倍放大正收益，减证据固定 ×1，不出牌必败。
- 监管方需把证据推进到阈值（困难 18）触发暴雷，并守住终局安全线。
- 终局按真实净资产（真实资产 − 真实负债）与安全线达标率结算胜负。

## 文件

- `index.html` —— 游戏本体与开始界面（GitHub Pages 入口文件）。
- `guide.html` —— 独立的新手指导页（完整玩法说明 + 全部卡牌图鉴），从开始界面点「📖 查看完整新手指导」跳转，内含「← 返回开始页」回到 `index.html`。
- `bgm.mp3` —— 背景音乐《朋友的酒》，Pages 站点默认加载；本地也可用开始界面的「📁 选歌曲」替换为自己的音频。
